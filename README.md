# 🌿 منصة عُمْرَان لإدارة الحلقات والمجمعات القرآنية
### *Omran Quran Halaqahs & Academy Management Multi-Complex System*

منظومة سحابية متطورة وشاملة لإدارة مجمعات وحلقات تحفيظ القرآن الكريم بمستوى احترافي عالمي. تم تصميمها خصيصاً للمبرمجين والمطورين، المشرفين العامين، مديري المجمعات، معلمي الحلقات، والطلاب وأولياء الأمور.

تتميز المنصة بدعم **تعدد المجمعات القرآنية (Multi-Complex)**، وإمكانية تخصيص **قاعدة بيانات سحابية مستقلة (Isolated Firestore Database)** لكل مجمع قرآني بضغطة زر واحدة، مع نظام متقدم لربط المعلمين بحلقات متعددة في مجمعات مختلفة، ونظام الرمز الفريد (6 أرقام) لإلحاق المعلمين والمشرفين، ونظام تحميل فائق النعومة مانع للتعليق (Non-blocking Resilient Loading Suite).

## 🌟 أحدث التحديثات والميزات المضافة (Changelog & Latest Highlights)

### 1. ⚡ حل مشكلة التحميل وسرعة الاستجابة اللحظية (Zero Hang / Non-blocking Loading Suite)
- **شريط التحميل العلوي الذكي (TopProgressBar):** تم تزويده بمراقب أمان ذاتي (Watchdog Timer) يضمن اكتمال شريط التحميل وإخفائه خلال أقل من 1.4 ثانية، مما يمنع تعليق شريط التحميل أو توقفه عند 92%.
- **إلغاء عمليات المزامنة الثقيلة المتكررة:** تم نقل فحص ومطابقة بيانات الطلاب والحلقات ليعمل في الخلفية مرة واحدة فقط عند بدء التشغيل أو بطلب التحديث اليدوي، مما قضى نهائياً على بطء الانتقال بين الأقسام.
- **تأمين حالات المزامنة السحابية (Auto-dismissing Sync):** تمت إضافة مؤقتات أمان تضمن تصفير مؤشر المزامنة التلقائية فوراً لمنع تجميد واجهة المستخدم حتى في حالات ضعف الاتصال.
- **تحسين استدعاء البيانات في قسم تحضير المعلمين:** تم ضبط معايير الاستدعاء لمنع تكرار طلب البيانات من الخادم دون داعٍ عند تحديث الواجهات.

---

### 2. 👑 صلاحية المبرمج لربط المعلم بحلقتين في مجمعين مختلفين مباشرة
- **ربط مباشر دون الحاجة لرمز (Direct Multi-Complex Link):** يمتلك مبرمج ومطور المنظومة صلاحية حصرية ومباشرة لفتح أي حساب معلم وربطه بأي مجمع قرآني وبأي حلقة في أي مجمع بنقرات بسيطة من داخل جدول الحسابات دون الحاجة لإدخال الرمز الفريد.
- **عرض مجمعات المعلم بوضوح تام في جدول الحسابات (في مجمع كذا ومجمع كذا):** عند مبرمج ومطور المنظومة في قسم "حسابات المعلمين والمشرفين"، يظهر تحت عمود **(المجمع القرآني)** نص صريح يوضح المجمعات المنتسب إليها المعلم بشكل بارز ومفصل (مثال: `في مجمع الزبير بن العوام و مجمع الحربي`) مع شارات ملونة لكل مجمع ووسم `مشترك بين (2) مجمعات`، مع توضيح اسم المجمع التابع له كل حلقة في عمود الحلقات المخصصة.
- **عرض الحلقات مجمعة حسب المجمع:** في نافذة تعديل حساب المعلم، تظهر بطاقات أنيقة لكل مجمع قرآني تضم جميع حلقاته مع مربعات اختيار واضحة.
- **تحديث تلقائي لحظي للطرفين:** عند حفظ التعديلات من قبل المبرمج، يتم تحديث بيانات المعلم وتحديث سجلات الحلقات المختارة فوراً، لتصبح الحلقات مسندة له والمعلم مسنداً للحلقات على مستوى المنظومة السحابية.

---

### 3. 🔄 التنقل السلس بين الحلقات والمجمعات المختلفة للمعلم (Flawless Halaqah Switching)
- **القضاء على ارتداد التحميل (Zero Bounce-Back):** تم إصلاح مشكلة محاولة المعلم الانتقال للحلقة الثانية في مجمع آخر، حيث كان النظام يعيد تعيين الحلقة؛ والآن يتم الانتقال فورياً وتغيير مساحة العمل والمجمع تلقائياً دون أي ارتداد أو تعليق.
- **عرض اسم المجمع بجانب اسم الحلقة:** يظهر اسم المجمع القرآني بين قوسين بجانب اسم الحلقة في القائمة المنسدلة وشريط التنقل السريع للمعلم (مثال: `حلقة عثمان بن عفان (مجمع الزبير)` و `حلقة علي بن أبي طالب (مجمع الحربي)`).
- **منع خيار "الكل" للمعلم متعدد الحلقات:** التزاماً بالقواعد التربوية، المعلم لا يظهر له خيار دمج كل الحلقات "الكل"؛ بل يتنقل بدقة بين حلقته الأولى وحلقته الثانية لضمان الفصل التام بين الطلاب والحضور والدرجات.

---

### 4. 🔑 نظام الرمز الفريد للمعلم المكون من 6 أرقام (Teacher 6-Digit Unique Code)
- **رمز ثابت ومعتمد لكل معلم:** يمتلك كل معلم أو مشرف رمزاً فريداً من 6 أرقام يتم توليده بصيغة تشفير آمنة تضمن عدم تكراره إطلاقاً.
- **ظهور الرمز في نافذة تعديل الحساب العلوية:** عند ضغط المعلم أو المشرف أو المبرمج على زر **(الحساب)** في أعلى الموقع، يظهر رمزه الفريد بوضوح في أعلى الشاشة بلون ذهبي بارز مع زر نسخ سريع بنقرة واحدة.
- **خياران مرنان لإضافة المعلم للمشرفين:**
  1. **إنشاء حساب جديد:** تسجيل معلم جديد بالاسم الثلاثي ورقم الهاتف واسم المستخدم.
  2. **معلم مسجل بالفعل (إضافة بواسطة الرمز):** يقوم المشرف بلصق الرمز المكون من 6 أرقام، فيتحقق النظام فورياً ويعرض بطاقة المعلم، وبضغطة واحدة يتم إلحاقه بالمجمع والحلقة المحددة.

---

### 5. 📱 تجاوب كامل مع الجوال وتمرير أفقي سلس (Mobile Responsiveness)
- **سلايدر أفقي سلس (Smooth Horizontal Slider):** تم تحويل شريط المجمعات والحلقات وأزرار التبديل وأقسام المنظومة إلى تمرير أفقي انسيابي باللمس `slider-horizontal` يمنع تشوه الشاشة أو اهتزازها في الجوالات وشاشات الهواتف.
- **ظهور زر تسجيل الدخول والشعار في أعلى الشاشة:** تم ترتيب الهيدر ليكون متناسقاً تماماً ومقاساته متوافقة مع جميع أحجام الشاشات المحمولة.

### 1. 📖 تسجيل التسميع الفردي والمتعدد للسور (Evaluation Tab)
- تسجيل التسميع من سورة وآية إلى سورة وآية أخرى.
- مراجعة صغرى، كبرى، تراكمية، واختبارات الأجزاء.
- التحديد الذكي لورد الغد تلقائياً بناءً على حفظ اليوم.
- دعم الخطة الفردية للطلاب المقترحة عبر الذكاء الاصطناعي (AI Plan).

### 2. 👥 إدارة الطلاب والتسجيل (Students Tab)
- إضافة وتعديل ونقل الطلاب بين الحلقات والمجمعات المختلفة.
- استيراد وتصدير بيانات الطلاب بصيغ ملفات Excel و JSON.
- إمكانية تشغيل أو إيقاف التسجيل الذاتي للطلاب عبر الإنترنت.
- إلحاق الطلاب بالحلقات فورياً وتحديث إحصائيات كل حلقة.

### 3. ✅ حضور الطلاب وتحضير المعلمين الذكي (Attendance System)
- **حضور الطلاب:** رصد الحضور، الغياب، الاستئذان، التأخر بنقرة واحدة، مع حساب تلقائي لنسب الالتزام.
- **تحضير المعلمين الجغرافي (Teacher Shifts & GPS Attendance):**
  - ربط الفترات (العصرية، المسائية، الفجر) بجوامع ومساجد محددة على خرائط Google.
  - تحديد نطاق جغرافي مسموح به (Geofencing بالأمتار) لتحضير المعلم.
  - إمكانية التحضير الذاتي للمعلم أو التحضير الإداري اليدوي من قبل المشرف.

### 4. 📝 قسم الاختبارات السحابية والشهادات (Exams & Certificates)
- بنك أسئلة واختبارات قرآنية محددة بالأجزاء والأرباع.
- تصحيح ورصد درجات وتخزين الإجابات سحابياً.
- إصدار شهادات شكر وتقدير واجتياز أجزاء قابلة للتخصيص والطباعة فورياً.

### 5. 🏆 لوحة الشرف والمنافسة القرآنية (Leaderboard)
- احتساب تلقائي لنقاط الحفظ، المراجعة، الحضور، والسلوك.
- منح نقاط إضافية وأوسمة تشجيعية للطلاب المتميزين.
- عرض متصدري الحلقات على مستوى المجمع لرفع التنافس المحمود.

### 6. 💬 رسائل الواتساب الفورية وبوابة ولي الأمر (WhatsApp & Parent Portal)
- تجهيز رسالة يومية فورية لولي الأمر تشمل كل تفاصيل اليوم بنقرة زر واحدة.
- رابط مباشر للبوابة الحية للطالب `?portal=ID` لمتابعة الإنجاز بدون الحاجة لتسجيل دخول.

### 7. 📚 المكتبة والأرشيف والنسخ الاحتياطي (Library & Backup)
- رفع وتخزين ملفات المناهج والمذكرات واللوائح والخطط الدراسية.
- نسخ احتياطي شامل وتصدير قاعدة البيانات بصيغة JSON واسترجاعها في ثوانٍ.

## 🔐 الرتب والصلاحيات داخل المنظومة (RBAC & Roles)

| الرتبة / الصلاحية | نطاق الوصول | الصلاحيات البارزة |
| :--- | :--- | :--- |
| **المبرمج والمطور (Developer)** | كافة المجمعات وقواعد البيانات السحابية | إدارة المجمعات، الترقية، ربط المعلمين متعدد المجمعات دون رمز، النسخ الاحتياطي العام، الوصول للوحة التحكم الفنية. |
| **المشرف العام (General Supervisor)** | مجمعه المحدد وجميع حلقاته | إدارة جميع حلقات المجمع، إضافة معلمين بالرمز الفريد، اعتماد الدرجات، إصدار الشهادات، الاطلاع على كافة التقارير. |
| **معلم الحلقة (Halaqah Teacher)** | حلقاته المخصصة فقط (حلقة أو أكثر) | رصد التسميع، تحضير الطلاب، إرسال تقارير الواتساب، التنقل بين حلقاته المخصصة بين المجمعات، إدارة طلابه. |
| **الطالب وولي الأمر (Student / Parent)** | الملف الشخصي للطالب فقط | الاطلاع على درجات التسميع، سجل الحضور، مقرر الغد، لوحة الشرف والشهادات. |

## 💻 التثبيت والتشغيل المحلي (Local Development)

### المتطلبات الأساسية
- **Node.js**: الإصدار 20 أو أحدث.
- **NPM** أو **Yarn** أو **PNPM**.

### خطوات التشغيل:
```bash
# 1. استنساخ المشروع
git clone https://github.com/azmaltaeleme/omran-quran-platform.git
cd omran-quran-platform

# 2. تثبيت الحزم والمكتبات
npm install

# 3. إعداد المتغيرات البيئية
cp .env.example .env

# 4. تشغيل السيرفر المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
